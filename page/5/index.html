git config说明

发表于 2019-03-20 更新于 2024-05-12 分类于 技术 ， 工具 ， Git

概要

git config 指令用于设置用户名和邮箱。一般来说，把文件push到GitHub上后，GitHub上所显示的push该文件的用户的用户名，就是git config设置的用户名。由于邮箱地址是唯一的，因而可以用来标识用户身份，所以当邮箱名是注册GitHub时所使用的邮箱时，不论git config设置的用户名是什么，GitHub都会显示GitHub的用户名。
