使用SSH网址

概述

官方文档：

SSH URLs provide access to a Git repository via SSH, a secure protocol. To use these URLs, you must generate an SSH keypair on your computer and add the public key to your GitHub account.

使用SSH进行克隆的话必须使用SSH keys。SSH密钥对最直观的作用是让你方便的登录到 SSH 服务器，而无需输入密码。由于你无需发送你的密码到网络中，SSH 密钥对被认为是更加安全的方式。SSH密钥对由公钥和私钥组成。公钥就是一把锁，你把锁给别人，他用锁锁住东西后，除了你自己外其他人是没有钥匙(私钥)的，都无法打开。配对的私钥就是钥匙。必须保证使用你公钥的人明确知道这个公钥一定是你的。你可以在网站或通过其它方式公布你的公钥，以便他人进行对照确认。由于公钥很长，所以有了对应的指纹(指纹更易辨别，位数更少)，可以通过指纹进行对照(公布指纹)。公钥加密指纹fingerprint有两种形式：

  • 之前的十六进制形式：

从本地push文件到GitHub

使用HTTPS网址

概述

官方文档的说法：

When you git clone, git fetch, git pull, or git push to a remote repository using HTTPS URLs on the command line, you'll be asked for your GitHub username and password.

演示：使用 git push 将本地文件push到 GitHub 的 test 仓库

  1. 本地新建文件 test1.txt ，push到 test 仓库：

可以看到，本地在执行 git push 时被要求输入用户名和密码。
为了避免每次push都要输入用户名和密码，可以使用 osxkeychain helper 让 Git 记住 GitHub 的用户名和密码，这样，只要第一次push时输入了用户名和密码，Git 就会记住，之后再push就不必输入用户名和密码了。

安装 osxkeychain helper 的方法

(下面步骤全部来自参考链接2)
官方文档：

If you're cloning GitHub repositories using HTTPS, you can use a credential helper to tell Git to remember your GitHub username and password every time it talks to GitHub.
  • If you installed Git using Homebrew, the osxkeychain helper will already be installed.
  • If you're running Mac OS X 10.7 and above and you installed Git through Apple's Xcode Command Line Tools, then osxkeychain helper is automatically included in your Git installation.
